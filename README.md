# opencode-coolify
Running Opencode headless in Coolify Docker Container

Method 1: via Github Public Repo
Steps:
1. Open you Coolify Dashboard
2. Select your Project
3. Add New Resource
4. Select Git Based Public Repository
5. Enter repository url
6. Select Dockerfile under BuildPacks
7. Deploy the application

Method 2: via Dockerfile
Steps:
1. Open you Coolify Dashboard
2. Select your Project
3. Add New Resource
4. Select Dockerfile
5. Paste the code from the <a href="https://github.com/ammzz247/opencode-coolify/blob/main/dockerfile">Dockerfile</a>
6. Deploy the service
